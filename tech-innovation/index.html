🛠️ 科创模块

从赛事立项到成果路演，五大模块完整覆盖科创项目全流程，系统培养工程思维与动手能力。

课程模块

共 5 个模块，循序渐进，从基础到实战

🎯
模块一

科创工程设计

讲授科创赛事项目完整立项逻辑与设计流程，指导学生结合赛事规则确立课题。学习通过资料调研挖掘社会实际需求、完成课题可行性分析，掌握客户需求梳理、竞品对比分析、项目创新点挖掘方法，熟悉整体项目方案设计思路，建立完整的科创项目思维。

  • 赛事规则解析：深入研读白名单赛事规则，明确参赛方向与评审标准
  • 课题确立：结合赛事要求与个人兴趣，确立具备可行性的参赛课题
  • 资料调研：系统检索文献资料，挖掘真实社会需求与痛点
  • 需求分析：梳理客户需求清单，明确项目目标与功能边界
  • 可行性分析：从技术、成本、时间等维度评估课题可行性
  • 竞品对比：对比已有方案，明确自身项目的差异化定位
  • 创新点挖掘：提炼项目核心技术亮点与创新价值
  • 方案设计：输出完整项目方案，形成立项文档
赛事立项 课题调研 需求分析 竞品对比 可行性评估 创新设计
⚙️
模块二

机械基础与三维建模

整合机械理论与软件建模实操，理论部分系统讲解齿轮、带、链、凸轮、涡轮蜗杆等常见机械传动结构的特点与应用。实操部分以 Fusion 软件为核心，教学基础草图绘制、拉伸、旋转、放样等基础命令，以及阵列、投影、渲染、装配体等进阶功能。同时掌握游标卡尺尺寸测量、模型优化设计、云端保存、STL 格式导出与 3D 打印配套技能。

  • 机械传动理论：齿轮、带传动、链传动、凸轮、涡轮蜗杆等结构原理与应用场景
  • Fusion 基础建模：草图绘制、拉伸、旋转、放样等基础命令操作
  • 进阶功能：阵列、投影、渲染、装配体等高级建模技巧
  • 尺寸测量：游标卡尺精确测量实物尺寸，指导模型设计
  • 模型优化：结构轻量化、壁厚调整、支撑优化等设计方法
  • 云端协作：Fusion 云端保存与版本管理
  • STL 导出：模型格式转换与切片软件对接
  • 3D 打印：打印参数设置、后处理与成品验证
Fusion 360 机械传动 3D 建模 装配体 游标卡尺 STL 导出 3D 打印
💻
模块三

编程基础与嵌入式开发

包含基础语法与硬件编程两部分，基础阶段学习 C++ 程序结构、变量、输入输出、分支判断、多重循环、自定义函数、进制换算与各类运算符，同步拓展 Python 基础知识。嵌入式阶段掌握 Arduino IDE 操作、程序上传调试方法，可独立编写代码控制板载灯光、超声波传感器、WS2812B 灯带等设备，并学习 AI 辅助优化程序功能。

  • C++ 基础语法：程序结构、变量、输入输出、分支判断、多重循环
  • 函数与运算：自定义函数、进制换算、各类运算符
  • Python 拓展：同步学习 Python 基础语法与编程思维
  • Arduino IDE：开发环境配置、程序编写与上传调试
  • 板载灯光控制：LED 灯编程控制与呼吸灯效果实现
  • 超声波传感器：距离检测与避障逻辑编程
  • WS2812B 灯带：全彩灯带驱动与动态灯光效果
  • AI 辅助编程：利用 AI 工具优化代码逻辑与功能
C++ Python Arduino IDE 超声波传感器 WS2812B AI 辅助

模块四

电学基础与硬件实操

讲解电压、电流、电阻核心电学基础，串并联电路、断路、短路等电路知识以及万用表基础使用方法。依托 Tinkercad 平台完成电路虚拟仿真，结合面包板、杜邦线、LED 灯、电阻、滑动开关、Arduino Nano 等元器件，完成红绿灯电路实物搭建，熟练掌握各类基础硬件的接线与实操方法。

  • 电学基础：电压、电流、电阻的概念与计算（欧姆定律）
  • 电路知识：串并联电路、断路、短路的原理与分析
  • 万用表使用：电压、电流、电阻测量与电路排故
  • Tinkercad 仿真：电路虚拟搭建与仿真验证
  • 面包板接线：面包板布局、杜邦线连接规范
  • 元器件实操：LED 灯、电阻、滑动开关等器件使用
  • 红绿灯电路：从仿真到实物搭建完整红绿灯电路
  • Arduino Nano：主控板接线与程序烧录
电路基础 万用表 Tinkercad 面包板 Arduino Nano 红绿灯电路

模块五

小组科创综合项目实训

课程后期进入专项项目开发阶段，以小组为单位开展完整项目落地实操。基于前期所学知识，迭代优化三维模型并更新 3D 打印版本，调试、优化控制程序并修复功能 BUG，反复测试作品整体功能，完成作品组装、细节优化、路演彩排，最终进行项目成果路演展示，完整经历科创项目从设计、制作、调试到成果展示的全流程。

  • 小组协作：以团队形式开展项目，分工协作与项目管理
  • 模型迭代：基于前期设计迭代优化三维模型结构
  • 3D 打印更新：打印新版本零件，验证设计改进效果
  • 程序调试：控制程序调试优化，提升运行稳定性
  • BUG 修复：功能缺陷排查与修复，确保功能完整
  • 整体测试：反复测试作品整体功能与可靠性
  • 作品组装：机械结构、电路、程序整合组装
  • 细节优化：外观打磨、线束整理、功能微调
  • 路演彩排：展示演讲准备与模拟演练
  • 成果路演：正式展示项目成果，接受评审
