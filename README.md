## 三、统一风格是怎么实现的（技术说明）

- 每个子页面 `<head>` 内引入了 `assets/css/site.css`（在页面原有样式之后加载），提供：
  - 统一字体、绿色主色变量；
  - 统一顶栏 `.mb-sitebar`；
  - 将 `.page-toc`（左侧目录）与 `nav:not(.page-toc)`（页内吸顶导航）**下移 52px**，避让顶栏。
- 每个子页面 `<body>` 起始处注入统一顶栏，`</body>` 前引入 `assets/js/site.js`（回到顶部、导航高亮）。
- **各子页正文、表格、数据均未改动**，只改了"外壳"（顶栏/字体/入口）。这是一版安全的渐进式统一。

已知限制（v2 再处理）：
- 子页**内页配色**仍是原来的（如白名单页偏蓝、部分页偏蓝绿）。v2 会逐个把内页卡片、按钮、标题也统一到木白绿。
- 子页原有的"← 返回首页"链接仍保留（与顶栏并存，不影响使用）。

## 四、部署方法

> ⚠️ **重要：不要把 .zip 压缩包直接拖到 GitHub 网页上传框**
> GitHub Pages **不会自动解压**。即使上传成功，网站也不会更新，仓库里只会多一个下载文件。
> 网页上传经常报的 `Something went really wrong, and we can't process that file.` 也多数是上传压缩包导致的。
> **请先解压，再上传解压出来的文件/文件夹。**

**方式 A：网页上传（最简单，适合不装软件）**
1. 解压资料包。若用"仅改动文件"包（`mubai-site-v1-changed-only.zip`），解压后是 `index.html`、`README.md`、`assets/`、`articles/` 等，**目录结构已与仓库一致**，可直接覆盖。
2. 打开 `https://github.com/mubai100/mubai100.github.io`，点 **Add file → Upload files**。
3. 打开解压出来的文件夹，**Ctrl+A 全选**（务必包含 `assets` 等文件夹），拖进上传框。
   - 拖文件夹会保留子目录结构；只拖单个文件会全部堆在根目录，**会导致子页样式失效**。
4. 页面下方填提交信息（如 `v1: 主页改版 + 全站统一顶栏`），点 **Commit changes**。
5. 等 1–2 分钟，访问 `https://mubai.net.cn`（或 `mubai100.github.io`）验证，必要时 **Ctrl+F5 强制刷新**。

**方式 B：git 命令行（最可靠，推荐长期使用）**
```bash
git clone https://github.com/mubai100/mubai100.github.io.git
cd mubai100.github.io
# 把解压出来的文件覆盖到当前目录（保留 .git）
git add -A
git commit -m "v1: 主页改版 + 全站统一顶栏"
git push
```

**方式 C：GitHub Desktop（图形界面，可拖拽提交）**
安装后 Clone 该仓库 → 把解压文件覆盖进本地文件夹 → 填摘要 → Commit to main → Push origin。

**方式 B：本地预览**
- 双击 `index.html` 即可在浏览器打开（图片为相对路径，正常显示）。
- 或在本目录执行 `python3 -m http.server 8080`，浏览器访问 `http://localhost:8080`。

发布后请重点检查：
- [ ] 主页倒计时是否每秒跳动；
- [ ] 时间轴是否自动滚动、当前月份高亮；
- [ ] 点顶栏"政策通知/深圳中考/科创路径/找到我"能否跳到对应板块；
- [ ] 打开任一子页（如"深圳高中信息"），顶栏是否在顶部、左侧目录是否没被遮住；
- [ ] 手机端（窄屏）三栏是否堆叠、二维码是否正常。
